# Project Ideas

Build these only after learning the relevant fundamentals. Start small, then add features gradually.

1. **Personal profile page** — HTML and CSS
2. **Quiz or calculator** — JavaScript and DOM events
3. **Task tracker** — React, components, and state
4. **Notes API** — Node.js and Express
5. **Student task manager** — React, Express, and MongoDB
6. **AI study assistant (future)** — only after learning full-stack basics and introductory AI/API safety

For each finished project, include its purpose, features, setup instructions, screenshots if useful, and what you learned. Keep secrets and private user data out of Git.
