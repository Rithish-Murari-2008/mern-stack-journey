# Web Development Roadmap

Check a box only after practicing the topic and being able to explain the basics.

## 1. HTML and CSS
- [ ] Semantic HTML and page structure
- [ ] Links, images, lists, forms
- [ ] CSS selectors, box model, typography
- [ ] Flexbox and CSS Grid
- [ ] Responsive layouts
- [ ] Accessibility basics

**Practice:** Build a responsive personal profile page.

## 2. JavaScript
- [ ] Variables, types, operators, conditions, loops
- [ ] Functions, arrays, objects
- [ ] Array methods and modules
- [ ] DOM events and form handling
- [ ] Promises, async/await, fetch
- [ ] Error handling and debugging

**Practice:** Build a task list or quiz without a framework.

## 3. React
- [ ] Components, JSX, props
- [ ] State and event handling
- [ ] Lists, keys, conditional rendering
- [ ] Forms and controlled inputs
- [ ] Effects and data fetching
- [ ] Routing and component organization

**Practice:** Rebuild one earlier JavaScript project in React.

## 4. Node.js and Express
- [ ] Node and npm basics
- [ ] HTTP and JSON fundamentals
- [ ] Routes, middleware, controllers
- [ ] REST API design
- [ ] Validation and centralized error handling
- [ ] Environment variables and configuration

**Practice:** Build a small API with in-memory sample data first.

## 5. MongoDB
- [ ] Documents and collections
- [ ] CRUD operations and queries
- [ ] Schema/data modeling concepts
- [ ] Indexes and basic data validation
- [ ] Connect an Express API to a database

**Practice:** Persist data for your small API.

## 6. Full-stack project quality
- [ ] Connect React to your API
- [ ] Loading, empty, and error states
- [ ] Authentication and authorization fundamentals
- [ ] Secure password handling and input validation
- [ ] Basic automated tests
- [ ] Deployment and environment configuration
- [ ] Clear project README and screenshots

Do not rush authentication or security topics. Use trusted documentation and never commit secrets.
