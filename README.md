# MERN Stack Journey

My step-by-step learning path toward full-stack web development with MongoDB, Express.js, React, and Node.js. I am starting with web fundamentals and will add projects as I learn.

## Learning sequence

1. HTML and CSS — structure, styling, responsive layouts, accessibility basics
2. JavaScript — syntax, functions, arrays, objects, DOM, modules, async/await
3. Git and browser tools — commits, branches, debugging, DevTools
4. React — components, props, state, events, forms, effects, routing
5. Node.js and Express — server fundamentals, routes, middleware, REST APIs
6. MongoDB — documents, collections, queries, data modeling
7. Full-stack integration — validation, authentication, error handling, testing, deployment

## Folders

- `01-html-css/` — web page foundations
- `02-javascript/` — programming and browser interactivity
- `03-react/` — frontend UI
- `04-node-express/` — backend and APIs
- `05-mongodb/` — database fundamentals
- `projects/` — small projects and project ideas

## Learning rule

Build a small exercise at each stage before moving on. Do not put passwords, API keys, tokens, or real secrets in this repository. Keep local `.env` files out of Git.
